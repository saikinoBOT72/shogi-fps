# 銃の作り方と今後の計画

見本：デザートイーグル（`src/guns/deagle.ts`）。形・塗装・動きは開発用ページ **http://localhost:5173/guns.html** で確かめられる。

## 方針

- **実銃を元に、ローポリで。** 実銃の寸法（mm）で横から見た形を書き、厚みを付けて押し出す。角は小さく面取りして、トゥーン調の段々の陰影がきれいに乗るようにする。丸い部品も角を少なく（6〜8角）。
- **部品に分ける。** 動く部品（スライド・撃鉄・引き金・弾倉など）は回転の中心（ピボット）付きの入れ物に入れる。動かない部品は塗りごとに1つにまとめて、描く回数を減らす（重いPC向け）。
- **塗りの場所（スロット）で塗装する。** 形と色を分けておけば、スキンは「スロットごとの色の表」を足すだけで増やせる。
- **動きはキーで書く。** 「何秒でどの部品をどれだけ動かす」を表で書く。リロードは長さ 1 で書き、武器のリロード時間に合わせて伸び縮みさせる。

## 仕組み（ファイル）

| ファイル | 役目 |
|---|---|
| `src/guns/kit.ts` | 図面（u=後ろ→前 mm、v=下→上 mm）から部品を作る道具。`extrude`（横から見た形を押し出す・穴・上を細く）、`box`、`rod`、`ring`、`PartBuilder`（動く部品の入れ物・塗りごとにまとめる） |
| `src/guns/anim.ts` | 動きの仕組み `GunAnimator`。`[部品, 'px'〜'rz'/'vis', [[秒, 値]…], 補間]` を足し合わせる。`hold`（最後の形で止まる）、出来事（`eject` など）も書ける |
| `src/guns/skins.ts` | 塗装。スロット＝ `slide / barrel / frame / grip / detail / mag`。`metal: true` で金属のつや（段々の映り込みを描いた絵＝マットキャップ。光の計算が要らず軽い）、`tex` でグリップの表面（点々・木目・格子） |
| `src/guns/deagle.ts` | 見本の銃。部品・塗り・動き（fire / fireLast / release / reload / inspect / equip） |
| `src/gunview.ts` + `guns.html` | 確認用ページ。回す・塗装を変える・動きを再生・スロー |

ゲームとのつながり：`render.ts` の `buildPistol` がデザートイーグルを返す → `effects.ts` の `VM`（一人称の銃）が `VM.fire / reload / inspect / ready` で動きを流し、薬莢を飛ばす。リプレイも同じ動きを使う。

## 動き（今あるもの）

| 名前 | いつ | 中身 |
|---|---|---|
| fire | 撃ったとき | スライドが下がって戻る・撃鉄が落ちて起きる・引き金・薬莢が飛ぶ |
| fireLast | 最後の1発 | スライドが下がったまま止まる（弾切れが見て分かる） |
| reload | R / 弾切れ | 銃を傾ける → 弾倉が落ちる → 左手が新しい弾倉を入れる → 下がっていたスライドが戻る |
| inspect | V キー | 銃を回して横と上を眺める |
| equip | 対局の始め | 構えながらスライドを引く |

## スキン

今あるもの：黒鉄・銀・金・朱漆・青磁・藤（設定の「ハンドガンの塗装」で変えられる）。

増やし方：`SKINS` に1つ足すだけ。色はパレット（`src/palette.ts`）から選ぶ。

```ts
sakura: {
  name: '桜',
  slide: { c: P.momo[2] }, barrel: { c: P.nezumi[2], metal: true }, frame: { c: P.momo[1] },
  grip: { c: P.shiro[1], tex: 'stipple' }, detail: { c: P.kin[1], metal: true },
},
```

この先できること：
- **刻印・模様**：スライドや銃身の横に貼る絵（家紋・漢字・桜の枝など）。スロットに `decal` を足す
- **光る塗装**：`emissive` で線が光るもの（撃つと明るくなる、など）
- **駒ごとの既定の塗装**：歩は黒鉄、王は金、など。成り駒は専用の塗装で「上位版」らしく
- **手に入れる仕組み**：勝った回数や将棋モードの勝利で解放（オンライン対戦を入れるときに、持ち物として保存）

## この先の提案

1. **全部の銃を同じ作り方にする**（1丁ずつ）。実銃の候補：
   - 散弾銃（金）：レミントン M870（ポンプを引く動き）
   - サブマシンガン（銀）：MP5（コッキングレバー・曲がった弾倉）
   - リボルバー（桂）：S&W M29 / コルト パイソン（シリンダーが振り出される・撃鉄）
   - 狙撃銃（飛）：レミントン M700 / AWM（ボルトを起こして引く）
   - アサルトライフル（王）：M4 / 89式小銃（和風の駒に 89式 も合う）
   - グレネードランチャー（角）：M79（折って弾を込める）
   - 弓（香）：和弓（長い弓・弦を引く動き。今の弓を作り直す）
2. **成り駒は「上位版の銃」**（前に出た案）：同じ銃の改造版（長い銃身・照準器・大きい弾倉・光る塗装）にすると、部品とスキンの仕組みがそのまま使える。
3. **音も部品の動きに合わせる**：`magOut`（弾倉が落ちる）・`magIn`（入る）・`release`（スライドが戻る）の出来事はもう動きの中にあるので、そこで音を鳴らすだけでリロードの手ざわりが上がる。
4. **相手の駒の銃も動かす**：今は一人称だけ。相手が撃ったときにスライドが動く・リロードで弾倉が落ちる、を足すと、相手の様子が見て分かる（撃ち合いの駆け引きに効く）。
5. **腕を付けるかどうか**：今の手は「木の塊」で、駒らしくて軽い。腕を付けるなら、駒の木目の四角い腕（関節なし）くらいが絵柄に合う。

## 寸法の目安（デザートイーグル Mark XIX 6インチ）

全長 269mm・高さ 149mm・幅 32mm・銃身 152mm。見本はこの寸法で作り、一人称では 1.1 倍で見せている（`vmScale`）。
