# 将棋FPS

駒を取るとき、FPSの撃ち合いで決着する将棋。ブラウザで遊ぶ。

## 遊び方

- **将棋モード**：本将棋の初期配置で指す（持ち駒・成りあり）。駒を取りにいくと撃ち合いになり、攻めが勝てば取れる・負けると攻めた駒を取られる。相手の玉を取れば勝ち
- **撃ち合い**：好きな駒どうしで 1 対 1（相手は CPU）
- **友達と対戦**：部屋を作ると出る 4 文字のコードを友達に伝え、友達が入ると対戦（撃ち合い・将棋モードを選べる）（P2P。おたがいの IP アドレスが相手に伝わるので、知っている人とだけ）

将棋モードのルール：撃ち合いで逆転できるので、王手放置・千日手はあり（詰みでは終わらない。玉は撃ち合いで取る）。反則は打ち歩詰めだけ。
二歩は打てるが、打つとその筋の自分の駒が（打った歩も王も）爆発四散して消える。

操作はタイトル →「操作方法」で確認・変更できる（マウスの横のボタンにも割り当てられる）。
基本：WASD 移動（左Shift で走る）／マウスで狙う・左クリックで撃つ・右クリックで覗き込み／Space ジャンプ（壁に向かって長押しで登る）／1 ナイフ・2 メイン武器（ホイールでも切り替え）／E・Q スキル／R リロード／V 武器を眺める

## マップ

「一人で遊ぶ」の画面か、友達との部屋（部屋を作った人）で選ぶ。どちらも点対称。

- **谷と二つの丘**（132m）：左右の橋のたもとの関所から出撃。谷と川（中は遅い）、段々、自分の丘、崖の小道、高い吊り橋、谷の村
- **山寺の石段**（110m）：麓の山門から出撃。長い石段 → 中段（竹林・墓地）→ 境内の本堂と鐘楼。灯籠の灯りだけの薄暗いマップ
- **雪の温泉街**（110m）：坂の上の広場から出撃。外側の町（土産物屋・2階建ての旅館・屋根伝い）→ 石段 → 広場の足湯・竹垣 → 真ん中の露天風呂（中は遅い）と大岩。夜、提灯の灯りと降る雪。雪には足跡が10秒残る。雪だるま・湯桶・卓球台・石灯籠・そり・番傘などが物理で動く

木箱・酒樽・米俵・荷車・丸太・賽銭箱・手桶は物理で動く。

## 開発

Vite + TypeScript。three.js（描画）と cannon-es（物理）。

```
npm install        # 最初に1回
npm run dev        # 開発用サーバー（http://localhost:5173、保存すると即反映）。play.bat でも起動できる
npm run build      # 型チェックして dist/index.html を作る
npm run typecheck  # 型チェックだけ
node tools/fix-imports.mjs  # 型チェックで「名前が見つからない」ものの import を自動で足す
```

`main` ブランチに push すると GitHub Actions がビルドして GitHub Pages に公開する（`.github/workflows/deploy.yml`）。
開発中はブラウザのコンソールで `dev` から中身を触れる（例：`dev.game.player.hp`、`dev.step(60)`）。公開版には入らない。

### 決まりごと
- 色は `src/palette.ts` の固定パレットだけを使う（CSS では `var(--shu-1)` のように）
- 材質はトゥーン調・ローポリの面（`src/materials.ts`）
- 駒・武器・スキルの数値は `src/core.ts`。CPU のスキルの使い方は `src/ai.ts` の `SKILL_AI`

## ファイル

| `src/screens.ts` | タイトル・駒選び・設定・操作方法・一時停止・結果 |
