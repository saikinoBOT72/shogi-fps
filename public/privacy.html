将棋FPS（https://saikinobot72.github.io/shogi-fps/、以下「このゲーム」）は、個人（以下「作者」）が友人と遊ぶために作り、無料で公開しているゲームです。広告と課金はありません。

このページでは、このゲームで扱う情報（プライバシーポリシー）と、遊ぶときの決まり（利用規約）を説明します。

プライバシーポリシー

1. 集める情報

(1) ログインしたとき（Google LLC の Firebase Authentication を使います）

ログインの方法受け取る情報保存される場所
Google でログインGoogle アカウントの番号（ID）、メールアドレス、表示名、プロフィール画像の URLFirebase Authentication（ログインの記録）だけ。ゲームのデータベースには入れず、ゲームの画面にも出しません。
ゲスト自動で作られる番号だけFirebase Authentication

ログインの処理のため、Firebase Authentication は IP アドレスとブラウザの種類（User-Agent）を扱います。

(2) ゲームのデータベース（Google LLC の Cloud Firestore）に保存するもの

  • ユーザー番号（上のログインの番号）
  • ゲーム内の名前（英語の大文字3文字。最初はランダム。同じ名前を1人だけにするため、名前とユーザー番号の組も保存します）
  • 持ち物：スキン、装備、ポイント
  • クエストの進み具合、ログインボーナスをもらった日数
  • 最後に保存した日時（サーバーの時刻。ログインボーナスとクエストの日付の切り替えにも使います）

これ以外（メールアドレス、本名、電話番号、住所、支払い情報など）は保存しません。ゲーム内の名前に、本名の頭文字など自分と分かるものは使わないでください。

(3) マーケットに出品したとき

出品すると、ゲーム内の名前・スキン・値段・出品した日時が、ログインしているほかのプレイヤーに見えます。売れると、買った人のユーザー番号と名前、売れた日時が出品のデータに入り、出品した人に「〇〇が買いました」と知らされます。出品のデータは、代金を受け取ったとき・取り下げたとき・期限切れで戻ったときに消えます。

(4) ほかのプレイヤーに見えるもの

ゲーム内の名前は、マーケットと、友達との対戦の相手に見えます。それ以外（持ち物・ポイント・クエストなど）は、ほかのプレイヤーには見えません。

(5) あなたのブラウザにだけ保存するもの（localStorage）

設定（感度・音量・キー設定など）、将棋モードの続き、持ち物の控え、CPU が覚えたあなたの一騎打ちの強さ。これらは外に送りません。ただし持ち物は、ログイン中はアカウントにも保存します。

(6) 友達と遊ぶとき

部屋のコードで相手とつなぐため、PeerJS の公開サーバー（0.peerjs.com）を使い、その後はブラウザどうしが直接通信します（WebRTC）。直接通信のため、相手のブラウザにあなたの IP アドレスが伝わることがあります。知らない人と部屋のコードを共有しないでください。送るのはゲームの進行に必要な情報（操作、駒の動き、装備しているスキン、ゲーム内の名前など）だけです。

(7) 集めないもの

アクセス解析（Google アナリティクスなど）、広告、Cookie による追跡は使いません。お金の支払いはないので、支払い情報も扱いません。

2. 使う目的

  1. ログインして、あなたのアカウントを見分けるため
  2. 持ち物を保存し、別の PC やブラウザでも同じ持ち物で遊べるようにするため
  3. ログインボーナスとクエストの進み具合を数え、ポイントを配るため
  4. マーケットでスキンを売り買いできるようにするため
  5. 不具合や不正な書き換えを調べて直すため

これ以外の目的には使いません。

3. ほかの人やサービスに渡すこと

作者は、集めた情報をほかの人に渡したり売ったりしません（法令にもとづいて求められたときを除きます）。このゲームは次のサービスを使っていて、それぞれのサービスが自社の決まりにしたがって情報を扱います。

  • Google LLC（Firebase Authentication・Cloud Firestore）：Firebase のプライバシーとセキュリティ、Google プライバシーポリシー
  • PeerJS（友達と遊ぶときの接続）：peerjs.com
  • GitHub, Inc.（このゲームの配信。アクセスの記録として IP アドレスなどを扱います）：GitHub のプライバシーに関する声明

4. 保存する場所

ゲームのデータベースは Google のサーバー（東京リージョン）に、ログインの記録は Google のサーバー（日本国外を含みます）に保存されます。

5. 保存する期間と消し方

  • アカウントの情報は、アカウントがある間保存します。
  • タイトル画面の左上 → アカウント →「アカウントを消す」で、ゲームのデータベースの情報（名前・持ち物・出品）とログインの記録を、あなた自身ですぐに消せます。出品中のスキンも一緒に消えます。
  • ゲストは、ログアウトすると同じアカウントには戻れません（持ち物も使えなくなります）。
  • ブラウザに保存したものは、ブラウザの「サイトデータを削除」で消えます。
  • 自分で消せないとき、または保存されている情報を知りたいときは、お問い合わせから連絡してください。

6. 安全のための取り組み

  • データベースは、本人しか読み書きできない決まりにしています。ほかの人の持ち物・ポイントは読めません。ほかの人に見えるのは、上の (3)(4) のものだけです。
  • メールアドレスなどの個人情報はデータベースに入れません。パスワードは扱いません（Google のログインは Google 側で行います）。

7. お子さまの利用

13歳未満の方は、保護者の方の同意を得てから遊んでください。Google でログインするには、Google の年齢の条件を満たす必要があります。

8. このポリシーの変更

保存する情報や使う目的を変えるときは、先にこのページを直し、ゲームの中でお知らせします。

利用規約

1. このゲームについて

このゲームは無料です。遊んだ時点で、この規約とプライバシーポリシーに同意したものとします。

2. ポイントとスキン

  • ポイントとスキンは、このゲームの中だけで使えるものです。お金で買うことはできず、お金やほかの物に換えることもできません。
  • ポイントは、ログインボーナスとクエストでもらえます（ログインした人だけ）。もらえる量やクエストの中身は、予告なく変えることがあります。
  • ガチャはポイントで引く無料の遊びです。出る確率はガチャの画面に書いてあります。

3. マーケット

  • ログインした人は、スキンを1人10個まで、1〜10,000pt の値段で出品できます。手数料はかかりません。
  • 出品したスキンは、売れるまで持ち物から外れます。いつでも取り下げられ、7日たつと自動で持ち物に戻ります。
  • 売れた取引は取り消せません。代金は、出品した人が次にゲームを開いたときに受け取ります。
  • 取引はプレイヤーどうしの責任で行ってください。作者は取引の内容について責任を負いません。
  • マーケットを使って、ゲームの外でお金などとやり取りすること（例：ゲームの外でお金を受け取り、安いスキンを高く買ってもらう）は禁止です。

4. してはいけないこと

  3. ほかの人を困らせる名前（悪口や差別的な言葉になる3文字など）を付けること
